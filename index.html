What we are building

A focused toolkit for independent research.

The planned application organizes permitted public listing information in one workspace. Features described below are proposals, not claims of a launched or Etsy-approved service.

01

Listing bookmarks

Save research references and record listing identifiers, titles, prices and user-written notes where permitted.

02

Tag and keyword review

Review tags returned by approved Etsy Open API endpoints, and distinguish source data from suggested keywords.

03

Product organization

Organize items with categories, research status, private annotations and comparison views.

04

Shop research

Explore public shop and listing metadata within the scope of approved access and Etsy's applicable data policies.

05

Export and restoration

Plan user-controlled backups for original research notes and permitted records, with backup before local upgrades.

06

Optional browser interface

A companion browser extension is proposed only if Etsy provides the express written authorization required for it.

Current stage

A responsible development process.

We are starting with the project description and access review. The research application will not enable API-based analytics or browser access outside Etsy's approved permissions.

01

Project overview and developer registration

Describe the intended functionality, users, and data handling accurately.

02

API access and written permissions

Request the appropriate API access and express written authorization for extension-based access or analytics when applicable.

03

Controlled integration and testing

Implement only the allowed API endpoints, credential safeguards, rate limits, and appropriate content refresh policies.

04

Private workspace and optional extension

Make approved features available to the intended users only after review and testing.

Transparency

Privacy and intended data use.

This section describes the current informational website and the data handling approach planned for the application. It will be updated before any application launch.

This website, today

This static website does not provide accounts, a login, a contact form, or a live application. It does not set first-party cookies or use embedded tracking or advertising scripts. GitHub Pages, as the hosting provider, may process technical connection information and IP addresses for its operations and security.

Planned application data, if approved

  • Intended scope: permitted public listing IDs, titles, listing tags, prices and shop references from official API endpoints, plus the operator's own notes and organization labels.
  • Not intended: buyers' private details, Etsy passwords, payment data, or private order information.
  • Security: keep API secrets off distributed client software; use appropriately secured server-side access when needed.
  • Retention: collect only necessary data, follow applicable Etsy API caching, display freshness and retention requirements, and enable removal of locally saved personal research records.
  • Sharing: no sale or redistribution of Etsy member content is planned.

Developer contact: Available via the public GitHub project owner profile after publication.

Independent and permission-first

Working within Etsy's API policies.

The project intends to use Etsy's official Open API only under the access scope and conditions granted by Etsy. It will not rely on unauthorized scraping or data feeds.

Permission requirement: Browser extensions accessing or analyzing Etsy data, and API access for analytics, require Etsy's express written authorization under the Etsy API Terms of Use. These capabilities are not enabled by this informational website and will not be launched without the necessary authorization.
